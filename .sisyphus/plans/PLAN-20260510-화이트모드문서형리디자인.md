## 요약
- StyleMatch 프론트를 shadcn 설치 문서 페이지 느낌의 화이트 모드 제품 UI로 정리합니다.
- 상세 문서는 `PLAN/PLAN-20260510-화이트모드문서형리디자인/PLAN.md`를 참조합니다.
- 업로드/추천/위시리스트의 기능과 문구는 유지하고 색상, 경계선, 여백, 카드 위계만 재설계했습니다.
- 후속 보정으로 GNB 헤더가 화면 전폭과 어긋나 보이던 문제를 분리해 상단 바를 풀폭으로 정렬했습니다.
- 추가 후속 보정으로 업로드 메인 카드를 참고 이미지에 맞춘 중앙 집중형 레이아웃으로 정리했습니다.
- 브라우저 주석 기준으로 업로드 제목 크기, 안내 문구 줄바꿈, 최근 업로드 카드 보조 문구 제거까지 미세 조정했습니다.
- 업로드 안내 문구/버튼 폰트 크기와 추천·위시리스트 새로고침 액션도 아이콘 중심으로 추가 정리했습니다.
- 업로드 안내 문구와 분석 버튼이 실제 화면에서 크게 보인다는 피드백을 반영해 체감 크기를 한 번 더 낮췄습니다.
- 업로드 안내 문구 span 가로 폭을 넓혀 문장 줄바꿈이 더 자연스럽게 보이도록 조정했습니다.
- 업로드 제목 아래 비어 보이던 여백은 프레임 상단 정렬과 간격 축소로 제거했습니다.
- 업로드 제목 아래 간격은 18px로 복원하고, 분석 버튼만 업로드 영역 바로 아래로 붙도록 재조정했습니다.
- 업로드 제목 아래 간격은 이후 피드백에 맞춰 28px로 다시 조정했습니다.
- 업로드 프레임 고정 높이는 제거하고, 업로드 영역과 분석 버튼 사이는 약 32px 수준으로 맞췄습니다.
- 분석 중 보조 문구는 더 넓은 폭을 쓰도록 바꿔 문장이 잘려 보이지 않게 조정했습니다.
- 추천/위시리스트 필터의 셀렉트는 가격 입력 필드와 같은 박스 스타일과 커스텀 화살표로 통일했습니다.
- 위시리스트 페이지 툴바는 필터와 새로고침이 좌측에 붙도록 다시 정렬했습니다.
