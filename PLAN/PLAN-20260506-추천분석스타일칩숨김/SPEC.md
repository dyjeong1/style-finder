## 1. 요구사항
1. 추천 분석 패널의 `톤/색상/무드/실루엣` 칩은 화면에 노출하지 않는다.
2. 스타일 칩 도출 설명 문구도 함께 노출하지 않는다.
3. 감지 카테고리/감지 품목/검색 힌트는 그대로 유지한다.

## 2. 상태 관리 규칙
- 스타일 칩 관련 값은 화면에서만 숨기고 상태와 API 응답은 유지한다.
- `AI 분석 기준` 배지와 감지 품목 정보는 계속 표시한다.

## 3. 검증 시나리오
- 추천 페이지에서 스타일 칩이 없다.
- 추천 페이지에서 도출 설명 문구가 없다.
- 감지 품목 텍스트는 그대로 보인다.
