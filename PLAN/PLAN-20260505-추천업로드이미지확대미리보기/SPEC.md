## 1. 요구사항
1. 추천 화면 상단의 업로드 썸네일을 클릭하면 확대 보기가 열려야 한다.
2. 확대 보기에는 현재 추천 기준 업로드 이미지가 더 큰 정사각형 비율로 표시되어야 한다.
3. 사용자는 닫기 버튼, 모달 바깥 영역 클릭, `Escape` 입력으로 확대 보기를 닫을 수 있어야 한다.
4. 업로드 이미지 로드 실패 시 기존 fallback 썸네일을 같은 위치에서 재사용해야 한다.

## 2. UI/UX 규칙
- 확대 진입 전 썸네일은 기존 추천 상단 위치를 유지한다.
- 썸네일은 버튼 역할을 가져야 하며 `aria-label`로 목적을 설명한다.
- 모달은 배경을 어둡게 덮고 중앙 정렬된 카드형 시트를 사용한다.
- 작은 화면에서는 모달 패딩과 radius를 줄여 안전 영역 안에서 보이게 한다.

## 3. 상태 관리 규칙
- `uploaded_image_id`가 바뀌면 이전 확대 모달은 자동으로 닫힌다.
- 현재 업로드 ID가 없는 경우에는 fallback 이미지를 그대로 사용한다.
- 추천 재조회 상태와 확대 모달 상태는 서로 독립적으로 유지한다.

## 4. 접근성 규칙
- 확대 영역은 `role="dialog"`와 `aria-modal="true"`를 가진다.
- 닫기 버튼은 명확한 `aria-label`을 가져야 한다.
- 키보드 `Escape`로 닫을 수 있어야 한다.

## 5. 검증 시나리오
- 추천 상단 업로드 썸네일 버튼이 보인다.
- 버튼 클릭 시 `추천 기준 업로드 이미지 확대 보기` 다이얼로그가 열린다.
- 닫기 버튼 클릭 시 다이얼로그가 닫힌다.
- `uploaded_image_id`가 바뀐 뒤에는 이전 모달 상태가 남지 않는다.
