## 1. 배경/문제 정의
- 비즈니스 맥락: 추천 결과를 볼 때 현재 어떤 업로드 이미지를 기준으로 상품이 추천되는지 더 분명하게 확인할 수 있어야 한다.
- 현재 성능/운영 이슈: 추천 상단에 업로드 썸네일은 추가되어 있지만 크기가 작아 세부 코디를 다시 확인하기 어렵다.

## 2. 목표/가설
- 1차 지표(Primary): 추천 화면에서 업로드 썸네일을 눌러 큰 이미지로 다시 확인할 수 있다.
- 2차 지표(Secondary): 확대 보기 진입과 닫기 흐름이 현재 추천 조회 상태를 깨지 않는다.
- 가설: 상단 썸네일을 모달 확대 보기로 연결하면 사용자가 추천 기준 이미지를 다시 확인하기 위해 업로드 화면으로 돌아갈 필요가 줄어든다.

## 3. 범위/산출물(Scope & Deliverables)
- 포함 범위:
  - 추천 상단 업로드 썸네일 클릭 액션 추가
  - 모달 기반 확대 미리보기 UI 추가
  - 닫기 버튼/배경 클릭/Escape 대응
- 제외 범위:
  - 업로드 이미지 편집 기능
  - 다중 이미지 갤러리
- 산출물(코드/모델/대시보드/문서):
  - `frontend/app/(main)/recommendations/page.tsx`
  - `frontend/app/globals.css`
  - 관련 PLAN/TASK/README/TODO 문서

- 데이터 품질/지연/누락: 업로드 이미지 URL이 깨진 경우에도 fallback 썸네일과 동일한 경로로 확대 표시가 가능해야 한다.
- 시스템/리소스 제약: 작은 화면에서도 모달이 화면 밖으로 넘치지 않도록 반응형 패딩이 필요하다.
