## 1. 요구사항
1. 추천 분석 패널에는 `감지 카테고리`, `감지 품목`만 남긴다.
2. `AI 분석 기준`, 분석 설명 문구, `검색 힌트`는 노출하지 않는다.
3. 감지 데이터 자체와 추천 동작은 그대로 유지한다.

## 2. 상태 관리 규칙
- 패널 제목 `업로드 분석`은 유지한다.
- 내부 상태값과 API 응답은 바꾸지 않는다.

## 3. 검증 시나리오
- 추천 페이지에서 `감지 카테고리`, `감지 품목`만 보인다.
- `AI 분석 기준`과 `검색 힌트:` 텍스트는 없다.
