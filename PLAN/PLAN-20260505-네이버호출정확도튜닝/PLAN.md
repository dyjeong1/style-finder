## 1. 배경/문제 정의
- 비즈니스 맥락: 추천 엔진이 아무리 좋아도 앞단의 네이버 쇼핑 후보가 노이즈가 많으면 최종 정확도는 제한됩니다.
- 현재 성능/운영 이슈: 네이버 쇼핑 API 호출은 사실상 기본 `sort=sim`만 활용하고 있어 중고/렌탈/해외직구 같은 불필요 후보를 요청 단계에서 충분히 줄이지 못합니다.

## 2. 목표/가설
- 1차 지표(Primary): 네이버 쇼핑 API 요청 단계에서 노이즈 상품 유형을 미리 줄인다.
- 2차 지표(Secondary): `sort`, `filter`, `exclude`를 설정값으로 열어 쿼리별 튜닝이 가능하게 만든다.
- 가설: 네이버 쇼핑 API 공식 파라미터를 적극 활용하면 추천 엔진 이전 단계에서 후보 품질을 더 안정적으로 끌어올릴 수 있다.

## 3. 범위/산출물(Scope & Deliverables)
- 포함 범위:
  - 네이버 쇼핑 API 호출 파라미터 설정 확장
  - `exclude`, `filter`, `sort` 반영
  - 관련 테스트 및 문서 갱신
- 제외 범위:
  - 추천 랭킹 엔진 자체 변경
  - 프론트 필터 UI 추가
