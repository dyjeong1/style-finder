## 1. 요구사항
1. 추천 페이지 헤더 아래의 자동 생성 검색어 노출 줄은 제거한다.
2. 업로드 분석 패널에는 tone/color/mood/silhouette 이 어떤 입력에서 계산되는지 짧은 설명을 제공한다.
3. AI 분석 결과에 `bag` 카테고리가 비어 있어도 규칙 분석에서 가방이 확실히 잡히면 해당 카테고리를 분석 결과에 제한적으로 합친다.
4. AI가 `바레즈` 같은 비표준 신발명을 반환하면 추천 화면에서는 서비스형 한국어 품목명으로 정규화한다.
5. 규칙 분석은 좌측에 든 가방처럼 기존 우측 편향 heuristic이 놓치던 전신 코디를 일부 더 복원할 수 있어야 한다.

## 2. 상태 관리 규칙
- 직접 입력 검색어 상태(`현재 직접 입력 검색어`)는 유지하되, 상단 요약 검색어 줄만 제거한다.
- 분석 칩 자체는 유지하고, 설명 문구는 분석 패널 안에서 항상 읽을 수 있게 둔다.
- 가방 보강은 AI 결과가 비어 있지 않은 상태에서 `bag` 카테고리가 빠진 경우에만 적용한다.
- 가방 보강은 기존 AI 감지 품목을 덮어쓰지 않고, 누락된 `bag` 항목만 추가한다.
- 신발 라벨 정규화는 카테고리를 바꾸지 않고 사용자 노출 item_label/query만 서비스형 표현으로 바꾼다.

## 3. 검증 시나리오
- 업로드 후 추천 페이지에서 상단 `검색어:` 텍스트가 보이지 않는다.
- 업로드 분석 패널에서 tone/color/mood/silhouette 근거 설명 문구가 보인다.
- `resolve_detected_items`가 AI 결과에 없는 `bag` 항목을 규칙 분석에서만 제한적으로 추가한다.
- `블랙 바레즈` 같은 응답은 `블랙 플랫 슈즈` 이상의 이해 가능한 표현으로 보정된다.
- 좌측에 든 가방이 있는 전신 코디 회귀 픽스처에서 `bag` query hint가 복원된다.
