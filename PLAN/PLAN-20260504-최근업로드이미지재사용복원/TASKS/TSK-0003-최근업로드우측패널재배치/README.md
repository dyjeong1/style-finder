## 목적
최근 업로드 목록을 업로드 카드 하단이 아니라 우측 세로 패널로 배치해, 새 업로드 영역과 재사용 영역을 한눈에 구분한다.

## 작업 내역
- [x] `/upload` 레이아웃을 좌우 2열로 재구성
- [x] 최근 업로드 패널을 우측 세로 리스트로 이동
- [x] 모바일에서 최근 업로드 패널이 자연스럽게 아래로 내려오도록 반응형 유지

## 산출물(Artifacts)
- `frontend/app/(main)/upload/page.tsx`
- `frontend/app/globals.css`

## 테스트/검증
- `cd frontend && npm run local` 재실행으로 최신 build 반영
- 인앱 브라우저 `http://127.0.0.1:3000/upload` 새로고침 후 최근 업로드가 우측 패널로 배치되는지 확인

## 의존성/리스크
- 최근 업로드 카드의 클릭/삭제 동작이 레이아웃 변경 후에도 그대로 유지되어야 한다.
