## 1. 배경/문제 정의
- 비즈니스 맥락: 검색어가 고도화될수록 추천 품질은 후보 수집보다 최종 랭킹이 더 크게 좌우됩니다.
- 현재 성능/운영 이슈: 추천 점수식은 `store.py` 안에 상수로 고정돼 있어 `품목명 일치`나 `비전 이미지 유사도` 영향도를 실험적으로 조정하기 어렵습니다.

## 2. 목표/가설
- 1차 지표(Primary): 추천 점수식의 핵심 가중치를 설정 가능한 구조로 분리한다.
- 2차 지표(Secondary): `품목명 일치 보너스`와 `비전 이미지 유사도 가중치`를 독립적으로 조절할 수 있게 한다.
- 가설: 후보가 충분히 좋아진 현재 단계에서는 랭킹 점수식을 더 세밀하게 나누는 것이 추천 품질 개선에 가장 직접적인 효과를 낸다.

## 3. 범위/산출물(Scope & Deliverables)
- 포함 범위:
  - 추천 점수 설정 객체 도입
  - 품목명 일치 보너스 추가
  - 비전 이미지 유사도 가중치 설정 분리
  - 관련 테스트 및 문서 갱신
- 제외 범위:
  - 외부 쇼핑 API 자체 정렬 로직 변경
  - 프론트 추천 카드 UI 개편
