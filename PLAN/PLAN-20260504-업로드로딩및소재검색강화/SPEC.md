## 제품 동작 기준
1. 사용자가 업로드 버튼을 누르면 분석 요청이 끝날 때까지 진행 상태가 시각적으로 표시된다.
2. 진행 상태는 버튼 문구뿐 아니라 스피너와 안내 문구로도 드러난다.
3. 감지된 품목 검색어는 가능하면 `색상 + 소재 + 품목` 형태를 우선 사용한다.
4. 소재 정보가 없으면 기존 `색상 + 품목` 형태를 유지한다.

## 구현 대상
- `frontend/app/(main)/upload/page.tsx`
- `frontend/app/globals.css`
- `backend/src/services/vision_outfit_analyzer.py`
- 관련 테스트 파일

## 테스트 기준
- 업로드 요청이 지연될 때 스피너와 진행 문구가 노출된다.
- `가죽`, `데님`, `스웨이드` 등 대표 소재가 검색어에 포함된다.
