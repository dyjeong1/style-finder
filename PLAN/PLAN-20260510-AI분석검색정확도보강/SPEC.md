## 1. 요구사항
1. AI가 감지한 카테고리는 유지하되, `가방`, `슈즈`, `팬츠`처럼 일반적인 품목명만 반환한 경우에는 같은 카테고리의 규칙 분석 세부 품목명으로 제한 보정할 수 있어야 한다.
2. 네이버 쇼핑 검색은 원본 AI query 외에 더 간결한 보조 query를 함께 사용할 수 있어야 한다.
3. 네이버 후보 목록은 API 응답 순서만 따르지 않고, query의 품목군/디스크립터/브랜드/의도와 얼마나 맞는지 기준으로 한 번 더 정렬해야 한다.
4. 최종 추천 랭킹은 exact 품목명 일치 외에도 같은 품목군과 핵심 디스크립터 정합성을 반영해야 한다.

## 2. 상태 관리 규칙
- AI가 감지하지 않은 새 카테고리를 규칙 분석으로 임의 추가하지 않는다.
- 보조 query 는 카테고리당 최대 1개만 허용한다.
- generic label 보정은 같은 카테고리 안에서만 수행하고, 기존 브랜드 정보가 있으면 유지한다.

## 3. 검증 시나리오
- `슈즈` / `가방` 같은 일반 품목명이 각각 `메리제인 슈즈` / `숄더백`으로 보정된다.
- `블랙 가죽 숄더백` query는 `블랙 숄더백` 보조 query를 함께 생성한다.
- `브라운 메리제인 슈즈` 검색 결과에서 `브라운 메리제인 슈즈`가 `브라운 로퍼`보다 앞선다.
- 추천 랭킹에서 `블랙 가죽 호보백`이 `블랙 캔버스 토트백`보다 더 높은 query 정합성 보너스를 받는다.
