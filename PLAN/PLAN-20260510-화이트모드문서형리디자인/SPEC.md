## 1. 목적
shadcn 설치 문서 페이지처럼 밝고 정돈된 제품 문서형 인상을 참고해 StyleMatch 핵심 화면을 화이트 모드 중심으로 재정리합니다.

## 2. 기능 스펙
- 업로드, 추천, 위시리스트 기능 동작은 그대로 유지합니다.
- 기존 버튼, 필터, 최근 업로드, 추천 카드, 위시리스트 카드의 데이터 표시 구조는 바꾸지 않습니다.
- 화면 전반의 색상, 경계선, 여백, 그림자, 헤더 위계만 재조정합니다.

## 3. 비기능 스펙
- 모바일 대응을 유지해야 합니다.
- 기존 접근성 구조(`skip-link`, `aria-*`, 포커스 상태)를 유지해야 합니다.
- 빌드 오류 없이 동작해야 합니다.

## 4. 구현 스펙
- `frontend/app/globals.css`에서 화이트 모드 토큰과 공통 컴포넌트 스타일을 재정의합니다.
- `frontend/components/app-shell.tsx`는 기존 구조를 유지하되 새 전역 스타일에 맞게 상단 셸이 동작하도록 둡니다.
- 업로드/추천/위시리스트는 기존 JSX를 최대한 유지하면서 레이아웃과 시각 위계만 전환합니다.
- GNB는 본문 `max-width` 제약과 분리해 상단 헤더 선과 배경이 전폭으로 보이도록 유지합니다.
- 업로드 메인 카드는 중앙 타이틀과 드롭존 중심의 단순한 레퍼런스형 구도로 재배치하되, 실제 업로드/분석 기능과 허용 이미지 문구는 유지합니다.
- 업로드 화면의 제목 크기, 안내 문구 줄바꿈, 최근 업로드 텍스트 표현은 브라우저 피드백에 맞춰 추가 미세 조정할 수 있습니다.
- 추천/위시리스트 툴바의 단순 보조 액션은 텍스트 대신 아이콘 버튼으로 대체할 수 있습니다.
- 업로드 카드의 본문/버튼 타이포는 CSS 단위 차이로 과대하게 보일 경우 실제 브라우저 체감 기준으로 추가 보정할 수 있습니다.
- 업로드 안내 문구는 필요 시 별도 폭 기준을 둬 줄바꿈 밀도를 조정할 수 있습니다.
- 업로드 카드 상단 제목과 드롭존 사이 여백은 그리드 정렬과 gap으로 미세 조정할 수 있습니다.
- 업로드 버튼 위치는 섹션 외곽 gap 대신 버튼 행의 개별 오프셋으로 별도 조정할 수 있습니다.
- 상단 제목과 드롭존 사이 gap 값은 사용자 피드백에 따라 18px, 28px 등으로 세밀하게 재조정할 수 있습니다.
