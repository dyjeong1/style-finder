## 1. 배경/문제 정의
- 비즈니스 맥락: AI가 주얼리나 양말 같은 악세사리를 감지하고 검색어까지 만들더라도, 추천 페이지에서 해당 카테고리 상품이 보이지 않으면 추천 신뢰도가 크게 떨어진다.
- 현재 성능/운영 이슈: 전체 추천 결과를 점수순 상위 `limit`로만 자르다 보니, 악세사리 후보가 수집되어도 다른 의류 카테고리에 밀려 추천 페이지에서 섹션 자체가 사라질 수 있다.

## 2. 목표/가설
- 1차 지표(Primary): 감지된 카테고리와 검색 힌트가 존재하는 경우, 추천 결과 상위 제한 안에서도 해당 카테고리 상품이 최소 1개는 남는다.
- 2차 지표(Secondary): 전체 추천 랭킹 순서는 최대한 유지되고, 카테고리 필터 동작은 바뀌지 않는다.
- 가설: 감지된 카테고리별 최소 1개 노출을 보장하면 악세사리처럼 후순위 카테고리도 추천 페이지에서 안정적으로 보인다.

## 3. 범위/산출물(Scope & Deliverables)
- 포함 범위:
  - 전체 추천 결과 제한 시 감지 카테고리 최소 노출 보장
  - 악세사리 카테고리 회귀 테스트 추가
- 제외 범위:
