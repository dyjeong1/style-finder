## 1. 요구사항
1. 추천 기준 업로드 이미지 확대 보기는 배경 dimmed 처리 없이 화면 상단에 떠야 한다.
2. 확대 카드 내부 우측 상단에는 `X` 닫기 버튼이 있어야 한다.
3. `X` 버튼 클릭과 `Escape` 입력으로 확대 보기를 닫을 수 있어야 한다.

## 2. 상태 관리 규칙
- 확대 보기 열림 상태는 기존 `isUploadedImageModalOpen` 상태를 재사용한다.
- 배경 클릭 닫기 대신 명시적 닫기 버튼을 기본 닫기 수단으로 사용한다.
- 확대 이미지는 기존 업로드 이미지 프리뷰 URL과 fallback 경로를 그대로 사용한다.

## 3. 검증 시나리오
- 추천 상단 썸네일 버튼을 누르면 상단 오버레이 카드가 열린다.
- 오버레이 카드 안에 `X` 닫기 버튼이 보인다.
- `X` 버튼을 누르면 오버레이가 사라진다.
