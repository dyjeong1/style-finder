## 1. 배경/문제 정의
- 비즈니스 맥락: 추천 기준 이미지는 빠르게 다시 확인할 수 있어야 하지만, 추천 화면 전체를 가리는 강한 dimmed 모달은 탐색 흐름을 끊는다.
- 현재 성능/운영 이슈: 현재 확대 보기는 배경을 어둡게 덮는 모달 구조라 추천 화면 상단 UI를 완전히 가리고, 닫기 버튼도 텍스트 중심이라 시각적으로 무겁다.

## 2. 목표/가설
- 1차 지표(Primary): 추천 기준 이미지가 화면 상단의 가벼운 오버레이 카드로 열린다.
- 2차 지표(Secondary): 우측 상단 `X` 버튼과 `Escape`로 명확하게 닫을 수 있다.
- 가설: dimmed 배경을 제거하고 상단 오버레이 카드로 바꾸면 이미지 확인 후 다시 추천 리스트로 돌아오는 흐름이 더 가볍다.

## 3. 범위/산출물(Scope & Deliverables)
- 포함 범위:
  - 확대 보기 레이아웃을 상단 오버레이 카드로 변경
  - 이미지 우측 상단 `X` 닫기 버튼 추가
  - 열기/닫기 회귀 테스트 보강
- 제외 범위:
  - 업로드 이미지 편집 기능
  - 다중 이미지 캐러셀
- 산출물(코드/모델/대시보드/문서):

  - `frontend/app/globals.css`

- 데이터 품질/지연/누락: 이미지 로드 실패 시에는 기존 fallback 이미지를 그대로 사용한다.
- 시스템/리소스 제약: 오버레이는 추천 화면 스크롤과 크게 충돌하지 않도록 pointer-events 범위를 최소화한다.
